# Hemanth Chillara — Portfolio

Personal engineering portfolio showcasing applied AI systems, machine learning architectures, and full-stack web applications.

## 🚀 Featured Projects

- **Healthcare AI Diagnostic Assistant:** Intelligent clinical triage model delivering high-accuracy risk assessment and automated patient insight generation using Python, PyTorch, FastAPI, and React.
- **CineMatch Recommendation Engine:** Personalized movie discovery engine utilizing hybrid collaborative filtering, SVD matrix factorization, and content embeddings.
- **Clinical Triage & EHR Portal:** Full-stack healthcare portal with FastAPI, MySQL, JWT authentication, and interactive React dashboards.
- **High-Throughput Analytics API:** Resilient asynchronous REST API built with FastAPI to ingest, validate, and aggregate streaming telemetry metrics.

## 🛠️ Tech Stack

- **AI & Machine Learning:** Python, PyTorch, Scikit-Learn, Pandas, NumPy, Collaborative Filtering
- **Backend & Database:** FastAPI, MySQL, REST APIs, JSON, Pydantic, JWT Auth
- **Frontend & Web:** React, JavaScript (ES6+), HTML5, CSS3, Lenis Smooth Scroll
- **Tools:** Git, GitHub

## 💻 Local Development

To run this portfolio locally without external dependencies:

```bash
# Using Python's built-in HTTP server:
python -m http.server 8000
```

Open your browser at `http://localhost:8000`.

## 🌐 Live Deployment (GitHub Pages)

This static website can be hosted for free on GitHub Pages:
1. Navigate to **Repository Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select branch: `main` and folder: `/ (root)`.
4. Click **Save**.
